# Afterthought

**The moment after you scroll.**

Afterthought is a working prototype for the *Designing for Smart Living* module. It pauses you after what you watch on social media and asks one open question, so you notice how the content made you feel instead of swiping straight to the next post.

## Try it

Open the GitHub Pages link for this repository on any phone or laptop.

On iPhone: open it in Safari, tap **Share › Add to Home Screen**, and it opens full screen like an app.

1. Set an intention and choose what the app can see.
2. Tap **Open a demo feed** and swipe through five posts.
3. Answer the pause with one word (or try mashing keys to see what happens).
4. Name the feeling and watch the knot form.
5. Open **Weave** to see your week, one row per day.

## The concept

- **One word is enough.** Honesty is made as small as possible.
- **Faking never pays.** Skipping takes one 5-second breath; mashing keys gets a nudge, then a "loose thread" plus the same breath.
- **The system backs off.** After three skips or mashes in a row it asks what would help: fewer pauses, tap-only, or a day off.
- **Your weave.** Each pause becomes a dot motif inspired by Tangaliya daana weaving from Gujarat, where every dot is tied by hand and the weaver has to stop.

## Privacy

Everything stays in the browser on your device (`localStorage`). Nothing is uploaded. Settings › Delete everything clears it.
